# Task

Demonstrate comprehensive usage of Openfort React hooks in a React application.

## Requirements

Create a React app that:

1. Uses `useUser` from `@openfort/react` to check authentication state
2. Uses `useWallets` from `@openfort/react` to access wallet information and manage wallets
3. Uses wagmi hooks for blockchain interaction: `useAccount`, `useBalance`, `useChainId`, `useSwitchChain`
4. Uses `useSignOut` from `@openfort/react` for sign out functionality
5. Shows proper integration between Openfort hooks and wagmi hooks
